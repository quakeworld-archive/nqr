   Playoff qualification & clan news  060303  
 

The admin crew has had some short discussions about the playoffs. Because the original plan was to have 16 teams (and 4 groups of 4) in each cup, we have tried to work out a way of having all teams having a chance of being in the playoffs.

The top 2 clans in all groups will still qualify for the 'Pro' (still a working title) competition, but we have tweaked the rules for the 'Amateur' playoff.
Due to the fact that clans may drop out before the end of the group stages, we do not want to announce the details just yet, but let's just say that we will find a way for all clans to either have an automatic playoff spot, or a qualifying game for the playoffs.

   Seedings / Rules / Draw  060301  
 

All clan placings and seedings are now FINAL.

Clans were seeded after long discussions amongst the crew. The group of us did not agree entirely, so we cannot expect the clans to do so as well! We based our choices on personal views on clans' skill, line-up and EQL performance. We will not be making changes to these seedings, so please don't ask us to.



We have made some changes to the rules:

1) How clans are decided when level on points:

If teams are even on points in the table, the following will seperate the clans (in this order): The game(s) between the clans in question*, the map difference, number of maps won and finally the frag difference.

*This cannot be calculated by the website. The admins will clarify any issues before the plaoyffs have started. Additionally, if more than 2 clans are level on points, a new sub-group will be calculated for the games between those teams. The team that places highest in that group will be highest in the league. Please note there will not be any additional games for this.


2) Rules regarding 3on3/4on3:


Team: 4on4 only. NQR is a 4on4 league and all games MUST be played 4on4. If you cannot field 4 players, you should not be in the league.


3) We changed "No coaching whatsoever from inside the game is allowed" to "No coaching whatsoever is allowed".

4) We tweaked the minping rules:

If a fair server cannot be found, cmd minping (or rcon sv_minping) can be set to bring the AVERAGE ping of the lower pinging team closer to that of the opposition. The maximum permitted value of minping is 50, unless agreed otherwise.

Clans can also increase their pings by rerouting using Qizmo. This is the preferred option over minping for most players.

If clans cannot agree on servers, minping or rerouting, an admin should be asked to resolve the dispute. The decision of the admin is FINAL.




The group draw will be made using the MVDsv "CMD RND" command. The admin team will be on a selected empty QW server tomorrow (Thursday) from 21CET to do this. People wanting to view are welcome to do so - qizmo details will be announced in #NQR.

The draw will also be broadcast on TeamSpeak - again, the details will be announced in #NQR.
