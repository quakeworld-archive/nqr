   FuhQuake new version and rules update  050320  
 

FuhQuake build 675 has been released. Download links are in the news post below this one.

All those using FuhQuake in NQR should update to this new build immediately. The NQR rules have been updated accordingly.

f_version must now reply FuhQuake 0.31 (build 675), and f_ruleset must reply with ruleset: smackdown [rj scripts blocked]. To put this in effect you must have "-ruleset smackdown -norjscripts" on your command line.

Edit: The ruleset does NOT block KFjump. This must be disabled serverside by typing "tkfjump". This command only works in KTPro, but seeing as KFjump is only in KTPro, that shouldn't be a problem :)

   season is go!  050307  
 

NQR8 is officially live!

Just a few things to update y'all on:

The new FuhQuake "official" release is not out yet and I have been told by Fuh Himself that it won't be out until Wednesday at the earliest.
As there is no security module for the release we are asking all players to continue to use 0.31 build 650. The crew does not want to see incidences of players using autotook or other automated team messages nor rocket jump scripts; any players caught using any of these will be reprimanded according to the rules. We realise that this is largely an issue of trust so please do not abuse this trust that we have in you the players :)

There is also not yet an official EZQuake release and so unfortunately EZQuake will not be allowed for use in NQR8 until that official release is public. This is because the crew had already voted to not allow EZQuake into NQR8 and our verdict was only reversed when we were told about the changes made in the final build. Sorry to disappoint you EZQ fans, but you'll have to hang on a while longer.

Finally, you can read gaz's first column article of the season by clicking here. Enjoy.

//The NQR Crew
