   RSS feed change  060506  
 

The NQR match RSS feed can now be found here:

http://nqr.nu/rss.php[?][short=1][&][limit=5]

This change was made to avoid having to change between seasons.

Additionally, you can now specify how many results to pull with the 'limit' querystring. For example, rss.php?limit=5 would return 5 results instead of the default 10.

You can also add short=1 to return the team names in their prefix form, along with the match scores.

So, an example full URL is:

http://nqr.nu/rss.php?limit=5&short=1

   Best of 5 system  060425  
 

This is just a short post to remind people about how the best of 5 map system works.

First of all, you must play all 3 maps (DM2, DM3, E1M2). You can do this in any order.

If it is 3-0 after 3 maps, then obviously the game is over.

If it is 2-1 after 3 maps, then you should follow this example:

Clan A vs Clan B. Clan A is winning 2-1 after 3 maps.

Clan B therefore chooses the 4th map. If Clan A wins, it's 3-1 and the game is over. If Clan B wins, it's 2-2, and Clan A should choose the decider map.

Therefore, if all 5 rounds are used, 2 maps will be played twice, and one map will be played once.
